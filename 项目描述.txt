游戏密码图鉴助手（Seed 关联） - 需求与设计文档
一、 项目概述
本软件是一款专为 Windows 平台设计的轻量级本地桌面工具。旨在配合某款特定游戏，通过监听/读取游戏日志自动获取当前的 Seed（种子号），并将其作为唯一索引，查询本地数据库中该关卡对应的“5个固定图案的3位密码”。若数据库中存在记录则直接展示，不存在则允许用户手动录入并保存，以此实现密码的快速查询与沉淀。

二、 核心需求
自动提取：自动定位日志目录（C:\Users\{用户名}\AppData\Local\OPP\Saved\Logs），读取最新的 .log 文件，通过正则表达式抓取最新的 Seed 值。

数据查询：以提取到的 Seed 为主键，查询本地 SQLite 数据库。

状态展示与交互：

查有记录：直接展示 5 个图案对应的 3 位密码。

查无记录：展示空输入框，提示用户手动输入密码。

数据保存：用户输入密码后，点击保存，将当前 Seed 与 5 个密码绑定存入数据库。支持覆盖更新（同一个 Seed 再次修改）。

三、 系统架构与技术选型
开发语言：Python 3.x

界面框架：PySide6 (Qt for Python) - 原生桌面体验，轻量易打包。

数据库：SQLite 3 - 无需安装额外服务，单文件存储，随软件走。

打包工具：PyInstaller - 最终打包为独立 .exe 文件。

模块划分
UI 呈现模块：负责界面的绘制、状态切换（查看态/编辑态）。

日志处理模块：负责文件 I/O，寻找最新日志，使用正则 Seed:\s*(\d+) 提取最新数据。

业务逻辑控制：接收 UI 事件，调用日志模块，根据提取的 Seed 发起数据库查询，并决定 UI 渲染状态。

数据持久化模块：封装 SQLite 的增删改查（UPSERT 语法）。

四、 实现的功能列表
一键刷新：点击按钮，立即执行“读取日志 -> 提取 Seed -> 查库 -> 渲染”。

Seed 强关联：界面高亮显示当前识别到的 Seed，防止玩家对错图。

5位密码录入/展示：

限制只能输入 3 位字符（数字/字母）。

同一个控件既是展示框也是输入框。

查无数据时显示置灰提示语（Placeholder），有数据时显示明文。

智能保存：如果查到了数据，修改后点击保存执行更新；如果是新数据，点击保存执行插入。

五、 界面设计描述 (UI)
界面采用极简的垂直流式布局，分为上、中、下三个区域：

1. 顶部状态区
当前 Seed 展示：文字加粗，颜色醒目（如蓝色）。

刷新按钮：位于右侧，用于手动触发重新读取日志。

2. 中部核心数据区（5行卡片）
每行由两个部分组成（左右并排）：

左侧固定区：固定的图案标识（初期可用文字标签如“螺旋”、“骷髅”，后续可替换为本地图标）。

右侧输入区：一个宽度固定的文本输入框（最大长度限制3）。

逻辑说明：如果查不到数据，输入框为空，显示灰字提示 请输入3位密码；如果查到数据，直接填入。

3. 底部操作区
保存按钮：大尺寸按钮，绿色。点击后保存或更新数据，并弹出成功提示。

六、 数据库设计 (SQLite)
由于无需存储图片，数据表极其精简。
表名：seed_data

字段名	类型	约束/说明
seed	TEXT	主键 (Primary Key)，唯一索引
p1_code	TEXT	图案1对应的3位密码
p2_code	TEXT	图案2对应的3位密码
p3_code	TEXT	图案3对应的3位密码
p4_code	TEXT	图案4对应的3位密码
p5_code	TEXT	图案5对应的3位密码
update_time	DATETIME	记录最后一次修改的时间
