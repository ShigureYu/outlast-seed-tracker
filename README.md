# OPP Seed Tracker

《The Outlast Trials》辅助工具：从游戏日志读取当前的 Trial ID 与 Seed，在本地
SQLite 答案表里查出对应密码，用半透明置顶悬浮窗展示；查不到时可以就地录入。

## 当前支持的关卡

| 关卡 | Trial ID | 槽位 | 码长 |
|---|---|---|---|
| 对被告作出判决 | `CHJ_MT02` | 骷髅 / 螺旋 / 三角形 / 五角星 / 太阳 | 3 位 |
| 侦破谋杀案 | `RES_MT01` | 凶手 / 凶器 / 房间 | 1 位 |
| 清空保险库 | `MHS_MT01` | 三角形 / 骷髅 / 太阳·五角星 | 3 位 |
| 蛊惑孩童 | `FPI_MT01` | 第 1～4 位，每位从 9 个图案中选 | 1 位/格 |

`FPI_MT01` 的 9 个图案（按阅读顺序编号）：兔子、梅花、皇冠、方块、眼睛、火焰、爱心、月亮、黑桃。
界面直接显示图案名；点击格子会弹出 3×3 图案面板，不需要记数字。

日志里出现、但答案库还没有的关卡，程序会自动把 Trial ID 和地图名登记到本地库，
悬浮窗顶栏先显示地图名；等仓库补齐该关的配置后会自动同步，不需要更新 exe。

## 使用

1. 到 [Releases](../../releases) 下载 `OPPOverlay.exe`，放到一个固定文件夹（别放临时目录）。
2. 双击运行。首次启动会在**同目录**生成 `data/seed.db`，你的录入都保存在这里，
   覆盖升级 exe 不会丢数据。
3. 游戏请使用**无边框窗口**模式；独占全屏下悬浮窗不会显示。

## 操作

> 快捷键是窗口级的，需要先点一下悬浮窗让它获得焦点。

| 操作 | 说明 |
|---|---|
| 拖拽窗口 | 移动位置 |
| 双击数字或图案 | 进入编辑 |
| 点击图案格 | 弹出 3×3 图案面板；也可直接按数字 1～9 选择 |
| 空格 / Enter | 普通关卡跳到下一个输入框；图案关卡打开选择面板；最后一位选完且有改动时保存 |
| Ctrl + 空格 / Ctrl + Enter | 强制保存（允许留空） |
| `F5` | 重新读取当前 Seed |
| `Ctrl + F5` | 立即同步仓库数据 |
| 左下角「折叠」 | 只保留顶栏与折叠按钮 |
| 右上角 `×` | 退出程序 |

`Esc` 不做任何事（相关功能已移除）。

## 数据更新

启动约 1.5 秒后会自动从仓库拉取 `data/seed.db` 并合并，**不需要手动点同步**：

- 只补本地没有的记录，**不会覆盖**你已经有的密码值；
- 同一 seed 两边值不同时，保留本地值，明细写入 `data/conflicts.txt` 并提示一次；
- 关卡配置（显示哪些列、顺序、码长、图案映射）以仓库为准，会在启动时更新；
- 也可以在窗口内按 `Ctrl + F5` 立即触发一次同步。

仓库数据以 `master` 分支的 `data/seed.db` 为准。
