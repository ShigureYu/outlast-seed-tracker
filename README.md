# OPP Seed Tracker

《The Outlast Trials》中某个「地点 → 标志 → 密码」关卡的辅助工具。
从游戏日志读取当前 Seed，用半透明置顶悬浮窗显示对应密码；查不到时可以就地录入。

## 使用

1. 到 [Releases](../../releases) 下载 `OPPOverlay.exe`，放到一个固定文件夹（别放临时目录）。
2. 双击运行。首次启动会在**同目录**生成 `data/seed.db`，你的录入都保存在这里，
   覆盖升级 exe 不会丢数据。
3. 游戏请使用**无边框窗口**模式；独占全屏下悬浮窗不会显示。

| 操作 | 说明 |
|---|---|
| 拖拽 | 移动窗口 |
| 双击 | 折叠 / 展开 |
| `F5` | 手动刷新 |
| `Esc` 或 `×` | 退出 |

## 数据更新

启动后会自动检查仓库里的 `data/seed.db`：有新记录时底部提示一行「发现新数据」，
点「同步」即可。**只补新记录，不会覆盖你已经有的值**；两边不一致时会让你逐条选择。
